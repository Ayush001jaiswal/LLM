# Software engineer resumes

## What recruiters look for
Recruiters and hiring managers look for the programming languages and frameworks named in the job description, evidence of building and shipping real systems, and clear impact. They scan for languages, cloud experience, testing habits, and the size or importance of what was built.

## Common keywords
Languages: Java, Python, JavaScript, TypeScript, Go, C++, C#. Backend and web: Node.js, React, REST APIs, microservices, GraphQL, SQL, PostgreSQL, MongoDB, Redis. Cloud and delivery: AWS, Azure, GCP, Docker, Kubernetes, CI/CD, Git. Practices: unit testing, code review, Agile, system design, performance optimization, debugging. Use only the terms that match your real experience.

## Strong bullet patterns
Illustrative patterns, with placeholders instead of real numbers:
- "Developed REST APIs for [system] using [language] and [database], serving [users or requests]"
- "Reduced API response time by [X%] by adding database indexes and caching"
- "Wrote automated tests that raised code coverage to [X%] and reduced production bugs"
- "Migrated [component] from [old tech] to [new tech], improving [reliability or speed]"
- "Collaborated with [N] engineers and product managers to ship [feature] on a weekly release cycle"

## Projects and open source
Freshers should show two or three projects with the tech stack, what the project does, and a repository link. Describe what you built yourself and the problem it solved. Contributions to open source and hackathon results are useful additions.
